# zivana-core

Aiken smart contracts for the Zivana Protocol.

This repository contains the on-chain Cardano validators that execute 
the Zivana Protocol's distribution primitive, manage the $ZVN token 
minting policy, handle treasury operations, and enforce staking logic.

## What is Zivana Protocol?

Zivana is an open Layer 2 trust infrastructure protocol for the African 
informal economy. It makes economic capability visible, verifiable, and 
financeable without requiring informal actors to become formal first.

Full protocol documentation: https://github.com/zivana-labs/zivana-docs
